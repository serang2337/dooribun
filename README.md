# 두리번수학

만 3세~초1 · 집 안 물건을 찾아 찍으며 배우는 AI 수학 앱 (마을 건설형)

| 파일 | 내용 | 담당 |
|---|---|---|
| `missions.js` | 미션 제목·펭펭이 대사·힌트·부모 질문 | PM 임세랑, 디자인 안보영, 디자인 최예원|
| `style.css` | 디자인·공간·색·글꼴 (맨 위 `:root`) | 디자인 최예원 |
| `index.html` | 화면 구성 | 프론트 박보현 |
| `app.js` | 앱 동작·판정 | 프론트 박보현, 백 이채빈 |

수정은 항상 브랜치 → PR → 미리보기 확인 → 합치기. API 키는 올리지 않기.
